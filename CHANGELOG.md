# Changelog

## 0.3.0

- Added an optional Streamlit dashboard for dataset QC, structure exploration, and output downloads.
- Kept the dashboard as a presentation layer over the existing QC package.

## 0.2.0

- Refined terminology to distinguish validation, canonicalization, duplicate detection, and descriptor calculation.
- Added duplicate-group analysis alongside duplicate-row counts.
- Expanded QC outputs and JSON summary statistics.
- Improved CLI help text and user-facing input/error handling.
- Expanded tests and updated installation, usage, and scientific-limitations documentation.
